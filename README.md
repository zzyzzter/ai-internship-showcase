CareerConnect: AI Internship Showcase
CareerConnect is a modern web application dashboard designed to help students and professionals track their internship applications and discover new, personalized opportunities. This repository (ai-internship-showcase) contains the frontend source code for the platform.

🚀 Features
Application Tracking: Monitor the status of your current applications with visual progress bars and dynamic status badges (e.g., "Interview Scheduled", "Under Review", "Applied", "Accepted").

Recommended Opportunities: Browse a curated list of internships matched to your profile, complete with a personalized "Match" percentage score.

Detailed Job Cards: Instantly view essential details for each role, including company name, verification status, location, posting date, and a brief job description.

Quick Actions: Easily "Apply Now" or "Save" opportunities directly from the recommendation dashboard.

User Profile Integration: Displays logged-in user information with verification badges (e.g., "College Verified").

🛠️ Tech Stack
Based on the repository configuration files, this project is built with:

Core: React + TypeScript (TypeScript makes up 95.5% of the codebase).

Build Tool: Vite (vite.config.ts).

Styling: Tailwind CSS and PostCSS (tailwind.config.ts, postcss.config.js).

Package Manager: Bun (bun.lockb is present in the repository root).

Linting: ESLint (eslint.config.js).
